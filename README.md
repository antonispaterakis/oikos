# OIKOS — Sovereign Personal Intelligence

> *"Privacy isn't a feature. It's the architecture."*

> **Status:** vision stage — software MVP is the next milestone. No code yet.

## Core idea

A Linux app that runs a local AI on hardware you already own. Connect the devices you already have — phone, laptop, Apple Watch, Oura ring — and get an objective coach for peak performance, with **zero bytes ever leaving your home**.

Pure software. No hardware to sell — it runs on the server you already own.

## The problem

| Pain | Description |
|---|---|
| Friction | Manual logging kills consistency |
| Fragmented | 10 different apps, 0 connection between them |
| Exposed | Cloud means your most personal data sits on someone else's servers |
| Technical | Local AI exists, but setup means hours of pain |

## How it works

1. **Capture** — mic, motion, health metrics, screen. Bring your own device.
2. **Brain** — local Whisper transcription + local LLM + vector DB, running as a Linux app on your own server.
3. **Action** — computer-use automation updates your apps for you. Say "I had chicken for lunch" and the log writes itself.
4. **Guidance** — with clean, complete data, the AI becomes an objective coach.

## Why it's defensible

No cloud competitor can credibly say "your data never leaves" and mean it architecturally. Value compounds with every device you connect, with no lock-in.
